# Code Review 報告

## 1. 變更摘要

新增一個名為 `numberToAccountingstring` 的 TypeScript 函式，目的是將數字轉換為「會計格式字串」——通常是將負數以括號包裹（如 `-5` → `(5)`），正數則直接輸出為字串。本次為全新檔案，共 9 行。

---

## 2. 潛在問題 🔴

### 2.1 核心邏輯錯誤（嚴重 Bug）

```typescript
// 現有程式碼（第 3 行）
if (number < 9) {
```

**問題：** 判斷條件應為 `< 0`（負數），而非 `< 9`。會計格式的括號表示法是針對**負數**，目前的邏輯會把 `-100`、`0`、`1`、`5`、`8` 全部加上括號，而 `9`、`10`、`100` 才輸出為正常字串，邏輯完全錯誤。

```typescript
// ✅ 修正後
if (number < 0) {
  return `(${Math.abs(number)})`;
} else {
  return number.toString();
}
```

### 2.2 函式無回傳值（Implicit `undefined`）

當 `number == null`（即 `null` 或 `undefined`）時，函式不回傳任何值，隱式回傳 `undefined`。呼叫端若未處理此情況，可能導致執行期錯誤。

```typescript
// ❌ 問題：呼叫端不知道可能拿到 undefined
const result = numberToAccountingstring(null);
result.toUpperCase(); // 💥 TypeError: Cannot read properties of undefined
```

### 2.3 參數類型過於寬鬆（`any`）

使用 `any` 完全失去 TypeScript 的類型保護。傳入字串 `"hello"` 不會有編譯錯誤，但執行時 `Math.abs("hello")` 會回傳 `NaN`。

## 3. 程式碼品質 🟡

### 3.1 函式命名不符合慣例

```typescript

// ✅ 建議：完整 camelCase
```

### 3.2 缺乏回傳型別標註

TypeScript 最佳實踐建議明確標註回傳型別，提升可讀性與型別安全：

```typescript
// ❌ 現有
function numberToAccountingstring(number: any) {

// ✅ 建議

```

### 3.3 巢狀 `if` 可簡化

雙層 `if` 結構可利用 Early Return 模式攤平，提升可讀性：

```typescript
// ❌ 現有：雙層巢狀
if (number != null) {
  if (number < 0) { ... }
}

// ✅ 建議：Early Return
if (number == null) return '';
```

## 6. 改善建議

以下為完整重構版本：

```typescript
/**
 * 將數字轉換為會計格式字串。
 * - 負數以括號包裹：-5 → "(5)"
 * - 非負數直接轉為字串：5 → "5"
 * - null / undefined 回傳空字串
 */
export function numberToAccountingString(
  number: number | null | undefined
): string {
  if (number == null) return '';

  if (number < 0) {
    return `(${Math.abs(number)})`;
  }

  return number.toString();
}
```

若需要支援小數位數格式化（如財務報表常見的千分位與固定小數），可進一步擴充：

```typescript
export function numberToAccountingString(
  number: number | null | undefined,
  fractionDigits = 2
): string {
  if (number == null) return '';

  const formatted = Math.abs(number).toFixed(fractionDigits);

  return number < 0 ? `(${formatted})` : formatted;
}

// 使用範例
numberToAccountingString(-1234.5);  // "(1234.50)"
numberToAccountingString(9999);     // "9999.00"
numberToAccountingString(null);     // ""
```
